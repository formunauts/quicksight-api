# AGENTS.md

## Purpose

This repository contains operational Python scripts for Amazon QuickSight administration, auditing, and migration tasks.

## Environment

- OS: Windows (PowerShell examples below)
- Python: use the local virtual environment in `.venv`
- Required AWS role for most scripts: `QuickSightData`

## Standard Workflow

1. Activate environment:
   - `c:\Users\danie\Documents\projects\quicksight-api\.venv\Scripts\Activate.ps1`
2. Assume AWS role:
   - `awsume QuickSightData`
   - In Codex/non-interactive PowerShell, AWSume can leave `AWS_PROFILE` and
     `AWS_DEFAULT_PROFILE` as empty strings. Clear them in the **same shell
     session** before calling `aws` or Python/boto3, otherwise the AWS CLI
     fails with `The config profile () could not be found`:

```powershell
awsume QuickSightData
$env:AWS_PROFILE = $null
$env:AWS_DEFAULT_PROFILE = $null
aws sts get-caller-identity
```
3. Run scripts from repo root with venv Python:
   - `c:/Users/danie/Documents/projects/quicksight-api/.venv/Scripts/python.exe code/<script>.py ...`

## Safety Rules

- Prefer read-only audits before any migration.
- Use dry-run mode whenever supported.
- Only use write/apply flags after validating logs and impacted assets.
- Keep casing exact for QuickSight field names (field matching is case-sensitive).

## Logging Conventions

- Scripts write reports to `logs/` as `.txt` and often `.json`.
- Treat JSON reports as the source of truth for affected assets and change details.
- Keep backup artifacts generated by migration scripts (do not delete by default).

## Existing Useful Scripts

- Field usage audit:
  - `code/qs_find_field_usage.py`
- Dataset field replacement downstream (analyses/dashboards):
  - `code/qs_replace_dataset_fields_downstream.py`

## Example: Dry-run Dataset Field Replacement

```powershell
c:/Users/danie/Documents/projects/quicksight-api/.venv/Scripts/python.exe code/qs_replace_dataset_fields_downstream.py `
  --dataset-name Marketplace_Performance `
  --rename Agentur=id[Customers] `
  --rename Organization_Name=organization_id
```

## Example: Apply (only after review)

```powershell
c:/Users/danie/Documents/projects/quicksight-api/.venv/Scripts/python.exe code/qs_replace_dataset_fields_downstream.py `
  --dataset-name Marketplace_Performance `
  --rename Agentur=id[Customers] `
  --rename Organization_Name=organization_id `
  --apply
```

## Notes for Future Agents

- If credentials fail, re-run `awsume QuickSightData` in the same terminal session used to run the Python script.
- When reporting impacts, include:
  - count of analyses/dashboards changed
  - per-field replacement counts
  - list of affected assets
  - paths to generated logs
